### Описание заданий

#### Задание 1: Игра «Крестики-нолики» (Tic-Tac-Toe) с GUI
- **Класс:** `TicTacToeGame.java`
- **Суть:** Интерактивная игра 3x3 на Java Swing. Поддерживает поочередные ходы двух игроков, визуальное отображение текущего хода, динамическую проверку условий победы по всем 8 линиям (3 горизонтали, 3 вертикали, 2 диагонали), фиксацию ничьей и сброс игрового поля.

#### Задание 2: Графические анимации на Java Swing
- **Классы:** `BouncingBallAnimation.java`, `SnowfallAnimation.java`
- **Суть:**
  - `BouncingBallAnimation`: симуляция физического отскока мяча от границ окна с учетом вектора скорости и непрерывной перерисовкой по таймеру Swing.
  - `SnowfallAnimation`: многочастичная симуляция падающих снежинок с индивидуальными координатами, скоростями и размерами, создающая плавный эффект снегопада.

### Инструкция по сборке и запуску

#### Вариант 1: Быстрый запуск (Windows)
Запустите командный файл:
```cmd
run.bat
```

#### Вариант 2: Запуск вручную
```bash
# Компиляция:
javac -encoding UTF-8 TicTacToeGame.java BouncingBallAnimation.java SnowfallAnimation.java Lab4_Main.java

# Запуск:
java -Dfile.encoding=UTF-8 -cp . Lab4_Main
```
